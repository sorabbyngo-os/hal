# Hardware Abstraction

HAL provides a hardware-independent interface for every physical device.

Examples include:

- CPU
- GPU
- RAM
- SSD/HDD
- Network adapters
- Bluetooth
- Wi-Fi
- Cameras
- Microphones
- Speakers
- Displays
- Battery
- USB devices
- Sensors

Higher-level services never access hardware directly.

Instead they communicate through standardized HAL APIs.

This allows Sorabbyngo OS to support multiple hardware platforms without changing application code.
